# ADR-003 — Scratchpad Scope

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

MVP Scratchpad is Markdown/Plain Text + autosave + versions + dictation.

## Rationale

Avoids rich editor complexity and aligns with Second-Brain export.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
