# ADR-002 — Release Boundary

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

Public MVP release requires REST + MCP + release hardening.

## Rationale

Core can become an internal RC earlier, but agent integrations are part of the MVP value.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
