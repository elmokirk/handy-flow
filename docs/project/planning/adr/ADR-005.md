# ADR-005 — Append-only Attempts

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

Retries create new transcription attempts; prior attempts are never overwritten.

## Rationale

Enables audit, comparison and recovery.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
