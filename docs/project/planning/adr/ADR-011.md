## Decision

## Rationale

Reuses OpenAI-compatible local endpoints and avoids installer/license/VRAM scope.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
