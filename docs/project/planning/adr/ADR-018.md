# ADR-018 — Soft Delete and Purge

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision
Captures and Notes use Trash/Soft Delete; purge is a separate explicit confirmed action.

## Rationale
Reduces accidental source-data loss and makes recovery possible.

## Change control
Changing this requires E2+ escalation, owner decision where material, a superseding ADR and affected contract/ticket updates before implementation resumes.
