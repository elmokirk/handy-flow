# ADR-020 — Snippet Determinism

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision
Snippets are single-pass, left-to-right, longest-match-first and non-recursive.

## Rationale
Prevents loops, order ambiguity and implementation drift.

## Change control
Changing this requires E2+ escalation, owner decision where material, a superseding ADR and affected contract/ticket updates before implementation resumes.
