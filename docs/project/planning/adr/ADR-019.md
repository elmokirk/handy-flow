# ADR-019 — Normalized STT Pipeline

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision
Dictionary/custom-word correction plus deterministic cleanup produces `normalized_stt`; Snippets and LLM outputs are derived.

## Rationale
Dictionary fixes recognition errors and belongs to Knowledge Raw; expansions/transformations do not.

## Change control
Changing this requires E2+ escalation, owner decision where material, a superseding ADR and affected contract/ticket updates before implementation resumes.
