# ADR-001 — Raw Semantics

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

Knowledge raw is `normalized_stt`; preserve `engine_raw`.

## Rationale

Preserves exact engine provenance while giving knowledge systems a human-usable deterministic raw.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
