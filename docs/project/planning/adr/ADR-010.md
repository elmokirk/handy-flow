# ADR-010 — MCP Transport

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

MCP is read-only stdio in MVP.

## Rationale

Local agent-friendly, no network listener, minimal security surface.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
