# ADR-014 — Physical DB Filename

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

Keep existing `history.db` physical filename through MVP migration.

## Rationale

Reduces file-move migration risk while internal code can expose `AppDatabase`.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
