# ADR-007 — Query Service Boundary

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

REST/MCP use a stable QueryService instead of direct SQL.

## Rationale

Decouples external integrations from schema migrations.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
