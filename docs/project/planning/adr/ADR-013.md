# ADR-013 — Representation Versions

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

Derived representations store complete versions, not text deltas.

## Rationale

Simplifies debugging, recovery and external export.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
