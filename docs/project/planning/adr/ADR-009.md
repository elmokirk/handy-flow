# ADR-009 — REST Security

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

REST binds loopback only, requires a random bearer token in app user data, and has no wildcard CORS.

## Rationale

Protects private transcripts from ambient localhost/browser access without overbuilding OS credential integration.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
