# ADR-023 — Autonomous Agent Safety Budget

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision
Feature agents cannot perform destructive Git operations and get one implementation plus two focused fix cycles before escalation.

## Rationale
Bounds cost/rework and prevents agents from damaging shared history while self-recovering.

## Change control
Changing this requires E2+ escalation, owner decision where material, a superseding ADR and affected contract/ticket updates before implementation resumes.
