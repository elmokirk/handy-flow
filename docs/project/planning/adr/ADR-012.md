# ADR-012 — Raw Retention

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

Raw audio and source transcript data are preserved by default.

## Rationale

Personal archive/data integrity outweigh automatic storage cleanup.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
