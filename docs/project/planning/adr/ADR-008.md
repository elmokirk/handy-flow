# ADR-008 — REST Process

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

REST is a separate local companion binary and read-only in MVP.

## Rationale

Independent lifecycle and narrow blast radius.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
