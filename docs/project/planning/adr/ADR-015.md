# ADR-015 — Architecture Authority

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

Coding sub-agents implement frozen contracts and escalate architecture changes.

## Rationale

Prevents incompatible autonomous design decisions and keeps owner control.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
