# ADR-017 — Versioned Planning Control Plane

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision
The starter kit is imported to `repo/docs/project/` and committed during Bootstrap.

## Rationale
Makes RUN_STATE, ADRs, gate reports and architecture changes part of the same auditable Git history as code.

## Change control
Changing this requires E2+ escalation, owner decision where material, a superseding ADR and affected contract/ticket updates before implementation resumes.
