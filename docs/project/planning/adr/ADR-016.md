# ADR-016 — Canonical Custom Branch

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision
`custom/main` is created from the pinned baseline and is the sole base for all phase branches.

## Rationale
Prevents a later-created fork `main` from silently drifting from the planned source baseline.

## Change control
Changing this requires E2+ escalation, owner decision where material, a superseding ADR and affected contract/ticket updates before implementation resumes.
