# ADR-004 — Windows First

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision

Windows is the reference platform; cross-platform parity is not an MVP gate.

## Rationale

Optimizes for the owner's actual environment while keeping domain code portable.

## Change control

Any change requires:
1. an escalation;
2. owner decision where material;
3. a superseding ADR;
4. affected ticket/contract updates before implementation resumes.
