# ADR-022 — Metadata and Logging Privacy

[[planning/adr/INDEX|← ADR Index]]

**Status:** Accepted

## Decision
Window titles are opt-in; normal logs exclude transcript/note/prompt bodies and secrets.

## Rationale
Reduces accidental leakage of personal and project-sensitive data.

## Change control
Changing this requires E2+ escalation, owner decision where material, a superseding ADR and affected contract/ticket updates before implementation resumes.
